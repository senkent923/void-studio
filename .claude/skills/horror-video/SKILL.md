# Хоррор-ролики

Генератор: `tools/horror/build.py` в репозитории `senkent923/void-studio`
(в облачных сессиях — `/opt/void-studio/tools/horror/build.py`).
Зависимости: `pip install -r tools/horror/requirements.txt` (numpy, scipy, pycairo, edge-tts) и ffmpeg.

## Порядок работы

1. **История.** Оригинальная, не банальная, 60–70 слов (≈ 33–36 сек). Короткие предложения от
   первого лица. Обязателен поворот в конце, который переворачивает смысл (пример: тьма в деревне —
   не угроза, а защита, и герой сам привёл «его» своим фонарём). Последняя фраза — удар.
   Без кровищи и штампов вроде «это был сон».
2. **JSON истории** в `tools/horror/stories/<имя>.json` — образец `derevnya_bez_ognej.json`:
   - `text` — текст озвучки; `voice`/`rate`/`pitch` — голос (по умолчанию Дмитрий, -5%, -6Hz);
   - `scenes` — `{"at": индекс_слова, "scene": ..., "label": "01 / ЛЕС"}`;
     доступные сцены: `forest`, `village`, `door`, `inside`, `granny`, `follower`, `window`;
   - `events` — индексы слов для эффектов: `flicker` (мигание фонаря), `card` (карточка),
     `whisper`/`whisper_end`, `click` (фонарь гаснет), `window2`, `light_on` (свет + финальный удар);
   - `chunks` — сколько слов в каждом субтитре (сумма = число слов); `accents` — красные слова;
     `big_last` — крупное последнее слово; `max_gap`, `gaps`, `tail` — темп.
   Индексы слов: сначала один раз прогони `--preview 1 --work <папка>`, затем смотри `<папка>/words.json`.
3. **Новые сцены.** Если сюжету нужны другие места/персонажи — допиши функцию `sc_<имя>` в
   `build.py` в том же стиле (плоские фигуры, обводка #0c0d0f, серо-синяя палитра, свет — glow/beam)
   и зарегистрируй в `SCENES`. Новые реплики карточки — функция `card()`.
4. **Проверка кадров:** `python3 build.py story.json --work W --preview <сек> -o p.png`
   для 6–10 моментов; склей в лист и посмотри глазами: персонажи не сливаются с фоном,
   субтитры ничего не перекрывают, у каждой сцены своя деталь.
5. **Рендер:** `python3 build.py story.json --work W -o out.mp4` (≈2 мин).
   Проверь длительность, громкость (-14 LUFS) и размер (~25 МБ), отправь файл пользователю.
